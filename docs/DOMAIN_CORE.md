# Domain core

The first rebuild slice establishes a provenance-first observation model. Every datum must carry metric, value, unit, timestamp, source and quality class. Demo, estimated, imported, reported and measured values remain distinguishable.

## Privacy and safety
- No diagnosis, treatment recommendation or emergency triage is implemented here.
- Do not commit identifiable health records or secrets.
- A production service must add consent, access controls, retention/deletion policy, audit trails and encryption.
